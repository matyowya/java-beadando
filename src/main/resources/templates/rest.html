REST API

A szállodák RESTful API-ja. Alap cím: /api/szallodak

A lekérdezés mindenkinek elérhető, a létrehozás, módosítás és törlés admin felhasználóval (HTTP Basic) működik.

MetódusÚtvonalLeírásVálasz
GET/api/szallodakÖsszes szálloda200
GET/api/szallodak/{az}Egy szálloda200, 404
POST/api/szallodakÚj szálloda201, 400, 409
PUT/api/szallodak/{az}Szálloda módosítása200, 400, 404
DELETE/api/szallodak/{az}Szálloda törlése204, 404, 409

Kérés törzse (POST, PUT)

{
  "az": "TS",
  "nev": "Teszt Szálloda",
  "besorolas": 4,
  "helysegAz": 1,
  "tengerpartTav": 100,
  "repterTav": 20,
  "felpanzio": true
}
